# 🖥️ Учёт оборудования серверной комнаты

Современное веб-приложение для учёта внесения/выноса оборудования в серверной комнате с серверным хранилищем данных.

## ✨ Возможности

- **Серверное хранилище**: все данные хранятся в SQLite на сервере, доступны всем пользователям
- **Учёт оборудования**: внесение и вынос с защитой от дублирования
- **Сотрудники**: управление списком сотрудников (11 предустановленных)
- **Импорт/экспорт CSV**: поддержка UTF-8 с BOM для Excel
- **Статистика**: метрики системы, топ сотрудников
- **Журнал аудита**: полная история всех действий
- **Адаптивный интерфейс**: тёмная/светлая тема, мобильная версия
- **Docker**: готов к развертыванию на любом сервере

## 🚀 Быстрый старт

### Docker (рекомендуется)

```bash

# Скопировать конфигурацию
```

## 📖 Использование

### Основные сценарии

1. **Внесение оборудования**
   - Перейдите в "Оборудование" → "Внести"
   - Заполните форму: инвентарный номер, сотрудник, комментарий
   - Система проверит уникальность номера

2. **Вынос оборудования**
   - Откройте карточку оборудования
   - Нажмите "Вынести оборудование"
   - Выберите сотрудника и подтвердите действие

3. **Импорт данных**
   - Перейдите в "Данные" → "Импорт"
   - Загрузите CSV файл
   - Система покажет отчёт об импорте

4. **Экспорт данных**
   - Перейдите в "Данные" → "Экспорт"
   - Выберите "Все записи" или "Активное оборудование"
   - Скачайте CSV файл

## 🐳 Docker развертывание

### Базовые команды

```bash
# Собрать образ
docker compose build

# Запустить
docker compose up -d

# Остановить
docker compose down

# Посмотреть логи
docker compose logs -f

# Перезапустить
docker compose restart
```

### Конфигурация

Скопируйте `.env.example` в `.env` и настройте:

```bash
# Порт приложения
APP_PORT=4321

# Режим работы
NODE_ENV=production
```

### Хранение данных

Данные хранятся в SQLite базе данных в Docker volume `app-data`. При пересоздании контейнера данные сохраняются.

**Резервное копирование:**
```bash
# Экспорт базы данных
docker exec server-room-app cp /app/data/app.db /tmp/app.db.backup
docker cp server-room-app:/tmp/app.db.backup ./backup/app.db

# Импорт базы данных
docker cp ./backup/app.db server-room-app:/app/data/app.db
docker compose restart
```

### Обновление приложения

```bash
# Получить обновления
git pull

# Пересобрать и перезапустить
docker compose down
docker compose build --no-cache
docker compose up -d
```

## 📊 API Endpoints

### Equipment
- `GET /api/equipment` - Получить всё оборудование
- `GET /api/equipment/:id` - Получить оборудование по ID
- `POST /api/equipment` - Создать оборудование
- `POST /api/equipment/:id/take` - Вынести оборудование

### Employees
- `GET /api/employees` - Получить всех сотрудников
- `POST /api/employees` - Создать сотрудника
- `PATCH /api/employees/:id` - Обновить сотрудника

### Audit
- `GET /api/audit-logs` - Получить журнал аудита

### Stats
- `GET /api/stats` - Получить статистику

### Health
- `GET /health` - Проверка здоровья

## 📝 Формат CSV

### Экспорт

```csv
Инвентарный номер;Внёс;Дата внесения;Вынес;Дата выноса;Комментарий;GLPI заявка;Статус
"SRV-001";"Латышов Никита";"15.01.2024 10:30";"";"";"Сервер Dell";"#12345";"Активно"
```

### Импорт

Минимальный формат:
```csv
Инвентарный номер;Сотрудник;Дата;Вынес;Дата выноса;Комментарий;GLPI
SRV-001;Латышов Никита;15.01.2024 10:30;;;Сервер Dell;#12345
```

- Разделитель: `;` (точка с запятой)
- Кодировка: UTF-8 с BOM
- Первая строка: заголовок (игнорируется)
- Дубликаты активных номеров пропускаются

## 🐛 Решение проблем

### Порт 4321 занят

Измените порт в `.env`:
```bash
APP_PORT=8080
```

### Docker не запускается

```bash
# Очистить старые контейнеры
docker compose down -v

# Пересобрать без кэша
docker compose build --no-cache

# Запустить заново
docker compose up -d
```

### Данные пропали

Данные хранятся в Docker volume. Проверьте:
```bash
docker volume ls
docker compose logs
```

### База данных повреждена

```bash
# Остановить контейнер
docker compose down

# Удалить volume (ВНИМАНИЕ: все данные будут удалены!)
docker volume rm uchet_servernaya_app-data

# Пересобрать и запустить
docker compose up -d --build
```
