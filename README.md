# 🖥️ Учёт оборудования серверной комнаты

Современное веб-приложение для учёта внесения/выноса оборудования в серверной комнате.

## ✨ Возможности

- **Учёт оборудования**: внесение и вынос с защитой от дублирования
- **Сотрудники**: управление списком сотрудников (11 предустановленных)
- **Импорт/экспорт CSV**: поддержка UTF-8 с BOM для Excel
- **Статистика**: графики, метрики системы, топ сотрудников
- **Журнал аудита**: полная история всех действий
- **Адаптивный интерфейс**: тёмная/светлая тема, мобильная версия
- **Docker**: готов к развертыванию на любом сервере

## 📖 Использование

### Основные сценарии

1. **Внесение оборудования**
   - Перейдите в "Оборудование" → "Внести"
   - Заполните форму: инвентарный номер, сотрудник, комментарий
   - Система проверит уникальность номера

2. **Вынос оборудования**
   - Откройте карточку оборудования
   - Нажмите "Вынести оборудование"
   - Выберите сотрудника и подтвердите действие

3. **Импорт данных**
   - Перейдите в "Данные" → "Импорт"
   - Загрузите CSV файл (формат: инв.номер;сотрудник;дата;...)
   - Система покажет отчёт об импорте

4. **Экспорт данных**
   - Перейдите в "Данные" → "Экспорт"
   - Выберите "Все записи" или "Активное оборудование"
   - Скачайте CSV файл

Скопируйте `.env.example` в `.env` и настройте:

### Резервное копирование

Данные хранятся в `localStorage` браузера. Для резервного копирования:

1. **Экспорт через интерфейс**: страница "Данные" → "Экспорт"
2. **Ручное копирование**: откройте DevTools → Application → Local Storage

## 📝 Формат CSV

### Экспорт

```csv
Инвентарный номер;Внёс;Дата внесения;Вынес;Дата выноса;Комментарий;GLPI заявка;Статус
"SRV-001";"Латышов Никита";"15.01.2024 10:30";"";"";"Сервер Dell";"#12345";"Активно"
```

### Импорт

Минимальный формат:
```csv
Инвентарный номер;Сотрудник;Дата;Вынес;Дата выноса;Комментарий;GLPI
SRV-001;Латышов Никита;15.01.2024 10:30;;;Сервер Dell;#12345
```

- Разделитель: `;` (точка с запятой)
- Кодировка: UTF-8 с BOM
- Первая строка: заголовок (игнорируется)
- Дубликаты активных номеров пропускаются

## 🐛 Решение проблем

### Порт 4321 занят

Измените порт в `.env`:
```bash
APP_PORT=8080
```

### Docker не запускается

```bash
# Очистить старые контейнеры
docker compose down -v

# Пересобрать без кэша
docker compose build --no-cache

# Запустить заново
docker compose up -d
```

### Данные пропали

Данные хранятся в localStorage браузера. Очистка кэша браузера удалит данные. Используйте экспорт для резервного копирования.
